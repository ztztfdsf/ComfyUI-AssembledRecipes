# ComfyUI-AssembledRecipes

**拼装一次，处处直读** —— LoRA 拼装太慢？把拼好的权重快照成配方，下次直读，跳过拼装。

## 痛点

量化模型 + LoRA 时，ComfyUI 每次加载都要「反量化 → 合并补丁 → 重新量化」，
一个组合几分钟；换组合再拼一次。本插件把拼好的权重落盘复用，**拼一次，用一辈子**。

## 节点

| 节点 | 作用 |
|---|---|
| **配方快照·保存** | 放在生成链尾部（图保存之后）。生成完成后把「已拼装权重」存成 `models/assembled_recipes/<名字>.safetensors`（同名已存在则跳过） |
| **配方快照·直读** | 替代「模型加载器 + LoRA」：直读配方输出 MODEL，零拼装。附带**逐层流水**开关 |
| **逐层流水开关** | MODEL 直通 + 逐层流水开关（正常 LoRA 链路也能用）。逐层流水 = 权重逐 block 按需上卡，显存峰值极小、永不爆表，代价是稍慢 |

## 用法

1. **第一次**：正常跑图（模型加载器 + LoRA Loader），末尾接「配方快照·保存」，起个名字
2. **以后**：删掉加载器和 LoRA，换「配方快照·直读」选这个配方 → 出图秒进采样
3. **管理**：侧边栏「配方缓存」面板浏览/删除（删除 = 移入 `trash/` 子目录，可手动找回）

## 逐层流水

显存紧张、爆表、换页卡死时打开。它把模型驻留预算钳到 ~0：
权重逐层从内存流到 GPU，算完即走 —— 显存峰值 = 单层 + 激活。
比系统级内存交换快几个数量级；显存够用时别开（白搬砖）。

## 安装

ComfyUI Manager 搜 `AssembledRecipes`，或：

```bash
cd custom_nodes
git clone https://github.com/ztztfdsf/ComfyUI-AssembledRecipes
# 重启 ComfyUI
```

## 说明

- 配方 = 完整模型权重（含量化格式），体积 ≈ 模型本身；按需建、可删除
- 快照发生在生成结束时，捕获的是**已合并 LoRA 的最终权重**
- 不修改 ComfyUI 核心；逐层流水通过自有 patcher 实例绑定实现
